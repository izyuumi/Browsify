Need a hand?

Report a problem or request a feature through Browsify’s public issue tracker.

Before opening an issue

  • Check that your Mac is running macOS 14 or later.
  • Include the macOS version and Browsify version you are using.
  • Describe what you expected, what happened, and the steps that reproduce it.
  • Do not include private URLs, account details, or other sensitive information.
